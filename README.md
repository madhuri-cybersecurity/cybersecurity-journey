## Cybersecurity Relevance

During Week 1, I learned how CPU, RAM, storage, processes and operating system components are relevant to cybersecurity monitoring and investigation.

I also learned that unusual resource usage or an unknown process can be an indicator for investigation, but resource usage alone does not prove malicious activity.

## Learning Outcome

I built a basic understanding of computer system components and learned how to observe system activity using Windows Task Manager.
